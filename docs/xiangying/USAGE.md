# 放映前的准备

## 获取程序

在本仓库 Releases 有 Windows x64 附件时，下载完整ZIP并解压到独立目录，运行 `乡映.exe`。保留全部配套目录和文件。当前为早期目录版，未提供安装向导。

## 准备影片

确认你有权下载、保存和放映相应影片。内置浏览器检测到可用公开媒体时，可加入下载队列；没有资源或来源失败时，查看实际提示，不反复输入账号凭据。

下载/转换目标选择NTFS目录。等待完成后再同步到“我的片库”；也可导入已取得授权的本地文件。通过搜索、分类和筛选查找影片，打开文件位置、播放或复制导出。

删除任务、清理完成任务或删除片库条目保留媒体文件。下载和转换遇到同名目标时不会静默覆盖已有文件。

## 连接放映设备

用Windows或播放器将电脑画面输出到投影仪、电视或外接大屏；设备支持的投屏方式由系统、播放器和设备提供。乡映不承担投屏协议服务。

正式放映前，在实际设备上检查影片的完整播放、声音和画面。按观众年龄选择合适内容，保留合法片源及授权说明。

## 出现问题

记录版本、步骤与错误提示，反馈前移除凭据、私人链接和个人目录。认证下载、DRM媒体成功下载及边下边播均不在当前支持范围。
